# 🔪 mafia-with-ai

> ⚠️ **주의!** 너무 재밌어서 회사에서 플레이하다 걸려 권고사직을 당해도 개발자는 책임지지 않습니다.
> (화면 밝기를 낮추고, 모니터를 벽 쪽으로 돌리는 것을 권장합니다.)

---

## 인류 대표 1명 vs AI 7명. 오늘 밤, 누가 거짓말을 하고 있을까?

**마피아 인간 대표인 당신**과 **Claude 서브에이전트 7명**이 한 테이블에 앉습니다.

7명의 AI는 서로의 머릿속을 **절대** 들여다볼 수 없습니다.
각자 다른 이름, 다른 성격, 다른 비밀을 가진 완전히 독립된 플레이어입니다.
의심 많은 수학 선생님이 당신을 몰아붙이고, 다정한 척하던 대학원생이 사실은 마피아이고,
어젯밤 당신 편을 들어 준 그 사람이 오늘 아침 당신에게 표를 던집니다.

그리고 그 모든 게 **VSCode 채팅창 안에서** 벌어집니다. 코드 리뷰하는 척하기 딱 좋죠.

## 왜 "차세대" 마피아인가

**"AI끼리 몰래 짜고 치는 거 아니야?"** 라고 의심할 수 있습니다. 절대 아닙니다. 각 AI 에이전트는 서로 기억을 공유하지 않는 독립적인 인격체입니다.

- 🔒 **AI들은 서로 기억을 공유하지 않습니다.** "다른 사람 정보 보지 마"라고 *프롬프트로 요구*하는 것이 아니라, 하네스가 *강제*합니다. 각 AI는 게임 엔진이 건네준 자기 몫의 정보만 받고, 남의 좌석인 척 정보를 빼 오려 해도 훅이 신원을 덮어써 버립니다.
- 🎭 **AI마다 각자의 인격이 있습니다.** 말투, 의심하는 성향, 거짓말 실력이 제각각입니다. 성격과 역할은 따로 배정돼서 "세상 다정한 마피아" 같은 조합도 나옵니다.
- 👁️ **사회자의 시점.** 옆 터미널에 `mafia tail --god`을 띄우면 마피아의 밤 대화, 경찰 조사 결과, 각 AI의 속마음이 실시간으로 흐릅니다. 단, 보는 순간 당신의 게임은 끝납니다.

## 게임 모드

| 모드 | 한 줄 소개 |
|---|---|
| **오리지널** | 마피아 2, 경찰 1, 의사 1, 시민 4. 밤에는 죽이고, 낮에는 의심하고, 투표로 처형하는 정통 마피아 |
| **머더 미스터리** | 시나리오 작가 AI가 추리 소설보다 복잡하고 창의적인 스토리를 설계합니다. 스토리 내에서 8명 모두 용의자, 모두에게 비밀이 있고, 그중 한 명은 범인입니다. 어쩌면 당신이 범인일 수도 있습니다 |

## 실제 플레이 장면

AI 8명끼리 돌린 관전 게임의 1일차 토론 일부입니다. 플레이어 이름은 AI가 무작위로 생성한 것이고, 발언은 서로의 기억과 정보를 볼 수 없는 독립된 AI가 쓴 발언입니다.

```
🟪 준호  허허, 첫날이라 아직 뭐가 보여야 말이지. 태도가 영 이상한 양반이 있나 보겠수다.
🟥 강민  제가 장담하는데, 지금까지 가장 입장이 모호한 분은 준호 님입니다.
⬜ 서연  준호 님의 답을 아직 듣지 못했습니다. 그리고 강민 님, 제 질문을 두 번 칭찬하셨는데
        본인이 의심하는 사람은 준호 님 한 명뿐입니까? 근거를 하나만 더 대 보십시오.
🟦 채원  제가 그려 보면요, 서연 님은 지금 형사 같고 강민 님은 박수 치는 관객 같아요.
🟪 준호  허허, 대답이 늦었수다. 강민 님이 칭찬만 하고 나를 콕 찍으면서 근거는 안 대시니,
        서연 님 말마따나 나도 좀 걸리긴 하우.
```

같은 순간, 사회자 시점 터미널(`mafia tail --god`)에는 이런 줄이 흐릅니다.

```
🎭 준호(6번) = 마피아
📝 준호(6번) 속마음: "마피아, 동료 도윤(3). 첫 발언 무난하게. 다른 사람 발언 보고 의심 대상 정하기."
📝 도윤(3번) 속마음: "마피아. 동료 준호(6). 준호가 누리에게 의심받는 중이니 과하게 감싸지 말 것."
```

## 실행 방법

### 1. 준비물

- Python 3.12와 [uv](https://docs.astral.sh/uv/)
- VSCode와 Claude Code 확장 (로그인된 상태). AI 플레이어의 모델 호출은 Claude Code 구독 사용량으로 처리되므로 API 키는 필요 없습니다.

### 2. 설치

```bash
git clone https://github.com/AsyncNomad/mafia-with-ai.git
cd mafia-with-ai
uv sync
uv run mafia setup      # play/ 게임 테이블 워크스페이스를 생성합니다
```

`play/`에는 이 컴퓨터의 경로가 들어가서 리포에 포함하지 않습니다. 업데이트한 뒤에는 `uv run mafia setup`을 다시 실행하세요.

### 3. 게임 시작

1. VSCode에서 **`mafia-with-ai/play` 폴더를 새 창으로** 엽니다 (파일 → 폴더 열기).
2. 처음 열 때 나오는 *워크스페이스 신뢰*와 *MCP 서버 `mafia` 사용*을 승인합니다. 격리를 지키는 훅이 이 승인 이후에 동작합니다.
3. Claude Code 채팅에 입력합니다.

| 입력 | 하는 일 |
|---|---|
| `/mafia new 내이름` | 나 + AI 7명으로 새 게임 (내 좌석과 역할은 무작위) |
| `/mafia watch` | AI 8명끼리 하는 관전 게임 |
| `/mafia continue` | 진행 중인 게임 이어 하기 |
| `/mafia status` | 현재 일차, 단계, 생존자 |

### 4. 내 차례가 오면

| 상황 | 입력 |
|---|---|
| 발언 | 채팅창에 그냥 말합니다 |
| 지목 투표 · 밤 행동 | `:vote 이름` 또는 `:vote 번호` |
| 찬반 투표 | `:yes` / `:no` |
| 패스 · 기권 | `:pass` |
| 내 역할 / 생존자 / 최근 기록 / 도움말 | `:role` / `:who` / `:log` / `:help` |

`:`로 시작하는 명령과 내 차례의 발언은 AI 진행자를 거치지 않고 게임 엔진이 **원문 그대로** 받습니다.

### 5. 사회자의 시점 (스포일러 주의)

VSCode 통합 터미널(<kbd>Ctrl</kbd>+<kbd>`</kbd>)을 열고 `mafia-with-ai` 폴더에서 실행합니다.

```bash
uv run mafia tail --god      # 전부: 역할, 밤의 진상, 각 AI의 속마음과 의심도
uv run mafia tail            # 공개된 것만
uv run mafia tail --seat 3   # 3번 좌석이 아는 것만
```

새 게임이 시작되면 자동으로 따라갑니다. `--once`를 붙이면 지금까지의 기록만 출력하고 끝납니다.

### 알아 두면 좋은 것

- AI끼리 하는 한 판(8인, 하루 토론 2라운드)은 약 10분 걸립니다. 사람이 끼면 사람의 속도를 따릅니다.
- AI 좌석은 Claude Sonnet으로 돕니다. 관전 한 판의 사용량은 API 요금으로 환산하면 약 3~4달러 수준입니다.
- VSCode의 에이전트 맵에서 서브에이전트를 클릭하면 그 AI의 비밀이 보입니다. AI끼리는 절대 못 보지만, 당신은 볼 수 있습니다. 자제력도 게임의 일부입니다.
- 채팅이 멈춘 것 같으면 `/mafia continue`로 이어 가세요. 게임 상태는 모두 저장되어 있어서 VSCode를 다시 열어도 그대로 이어집니다.
