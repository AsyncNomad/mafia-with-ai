# 오리지널 모드

경찰과 의사가 있는 고전 마피아입니다. 8인 고정입니다.
구현: `src/mafia/modes/original/` · 설정: `OriginalConfig`

## 구성

| 역할 | 수 | 팀 | 밤 행동 |
|---|---|---|---|
| 마피아 | 2 | 마피아 | 팀 채팅(가시성 `Team`) 후 처치 대상 투표 |
| 경찰 | 1 | 시민 | 1명 조사 → 마피아 여부를 `Seats(경찰)`로 받음 |
| 의사 | 1 | 시민 | 1명 보호 |
| 시민 | 4 | 시민 | 없음 |

- 역할 배정은 `rng_for(seed, "roles")`로 섞습니다. 같은 시드면 같은 배정이 나옵니다.
- 역할 카드는 본인 좌석에게만 보입니다. 마피아는 카드에 동료 좌석이 함께 적혀 있습니다.
- AI의 인격(`config/personas/`)은 역할과 독립적으로 배정합니다(M2).

## 진행

```
[1일차 밤] 마피아 채팅 → 밤 행동(마피아·경찰·의사 동시)
→ [2일차] 아침 발표(밤사이 사망자) → 낮 토론 → 지목 투표 → (후보가 있으면) 최후 변론 → 찬반 투표 → (가결이면) 처형
→ [2일차 밤] … 반복
```

기본값은 밤 시작이다(`start_with_night = true`, 2026-10-30 사용자 요청). `false`로 두면 1일차 낮 토론부터 시작한다.

| 단계 | 규칙 |
|---|---|
| 낮 토론 | `discussion_rounds`(기본 2)라운드. 라운드마다 생존자 순서를 `rng_for(seed, "discussion_order", day, round)`로 섞어 공개하고, 한 명씩 차례로 발언합니다. 패스할 수 있습니다 |
| 지목 투표 | 생존자 전원이 동시에 비밀 투표하고 한꺼번에 공개합니다. 자기 자신은 지목할 수 없고 기권할 수 있습니다. **단독 최다 득표자만** 후보가 됩니다. 동률이거나 전원 기권이면 처형 없이 밤으로 넘어갑니다 |
| 최후 변론 | 후보가 한 번 발언합니다 |
| 찬반 투표 | 후보를 뺀 생존자가 투표합니다. **찬성 > 반대**이면 가결이고, 기권은 세지 않습니다 |
| 마피아 채팅 | 생존 마피아가 2명 이상이고 `mafia_chat_rounds` > 0일 때만 합니다. 라운드마다 생존 마피아 전원이 동시에 말합니다. 이 단계의 진입은 마피아에게만 보이고, 화면에는 "밤"으로만 표시됩니다. 밤 요청은 모두 비밀 요청이라 익명 별칭으로만 깨웁니다([하네스 계약 함정 11](../harness-contract.md)) |
| 밤 행동 | 마피아는 처치 대상, 경찰은 조사 대상, 의사는 보호 대상을 동시에 고릅니다. 마피아는 마피아를 고를 수 없습니다. 경찰은 자신을 조사할 수 없습니다. 의사는 `doctor_self_protect`(기본 허용)와 `doctor_repeat_protect`(기본 금지: 전날 밤 보호한 사람 제외)를 따릅니다 |
| 밤 해석 | 마피아 표가 가장 많은 사람이 대상입니다. 동률이면 `rng_for(seed, "mafia_tie", day)`로 정하고, 전원 기권이면 처치하지 않습니다. 대상이 의사의 보호 대상이면 생존합니다 |
| 아침 | 사망자를 공개합니다(`PlayerDied`, 원인은 `night`). 아무도 죽지 않았으면 `PeacefulNight`를 냅니다. 역할 공개 여부는 `reveal_role_on_death`(기본 비공개)를 따릅니다 |
| 승리 | 사망이 생길 때마다 판정합니다. 마피아가 0명이면 시민 승, 마피아 수 ≥ 나머지 수이면 마피아 승. `max_days`(기본 10)를 넘기면 무승부입니다. 끝나면 `RolesRevealed`로 전원 역할을 공개합니다 |

**전환 규칙:** 페이즈가 바뀌는 진행 단계는 이벤트만 냅니다. 새 페이즈의 요청은 다음 진행 단계에서 *갱신된 상태*를 보고 엽니다. 그래서 방금 죽은 좌석에게 요청이 가는 경우가 구조적으로 생기지 않습니다(시뮬레이션 불변식 #4).

## 가시성

| 이벤트 | 가시성 |
|---|---|
| `RoleAssigned` | 본인 |
| `Speech`, `DiscussionRoundStarted`, `NominationRevealed`, `ConfirmationRevealed`, `PlayerDied`, `PeacefulNight`, `RolesRevealed` | 공개 |
| `MafiaChatRoundStarted`, `MafiaChat`, `MafiaTargetChosen` | 마피아 팀 |
| `InvestigationResult` | 경찰 본인 |
| `NightResolved` (노린 대상, 보호, 조사, 실제 사망) | 신의 시점만 |
| 투표 원본(`ActionSubmitted`) | 투표한 본인. 결과는 공개 이벤트로 일괄 공개 |

## 좌석 응답

모든 요청은 패스나 기권을 허용합니다. 그래서 응답하지 않은 좌석에는 대체 행동으로 "패스/기권"을 적용합니다.

| 요청 종류 | 응답 형태 | 필드 |
|---|---|---|
| `discussion`, `defense`, `mafia_chat` | 발언 | `speech` (없으면 패스, 최대 600자) |
| `nomination_vote`, `mafia_kill`, `investigate`, `protect` | 대상 | `target` (`options` 중 하나, 없으면 기권) |
| `confirmation_vote` | 찬반 | `approve` (없으면 기권) |
| 모든 요청 공통 | — | `private_note` (본인만 보는 메모, 최대 1000자), `suspicion` ({좌석: 0~100}, 신의 시점 전용) |
